Query Types

A / AAAA: Standard website connections (IPv4 / IPv6 addresses).
HTTPS / SVCB: Modern secure connection and service metadata.
MX / NS: Mail server records and domain authority info.
TXT: Text data, often used for email verification (SPF/DKIM).
SRV / PTR / SOA: Service discovery, reverse DNS, and zone authority.
DNSKEY / DS: DNSSEC security records for authenticated DNS.
NAPTR / HINFO: Telephony (VoIP) and host hardware information.
ANY: General requests for all available records of a server.

Request Origin (Countries)

geo: Internal or local network traffic (Private IPs).
ISO Codes: International traffic categorized by country of origin.
-: Unknown or currently resolving origins.
