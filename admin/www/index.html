Router Configuration (Local Network)

Configure the IP address of this ShieldDNS server as your router's primary DNS resolver to protect all network devices automatically without client-side software.

Recommended DNS Server for your LAN:
{{.Host}}
FRITZ!Box Instructions →
  1. Open http://fritz.box in your web browser.
  2. Navigate to Internet → Account Information → DNS Server.
  3. Select "Use other DNSv4 servers" and enter {{.Host}} under Preferred DNSv4 server.
  4. (Optional) For local DHCP broadcast: Under Home Network → Network → Network Settings → IPv4 Addresses, set the IP as the local DNS server as well.
  5. Click Apply.
OpenWrt Instructions →
  1. Log in to LuCI web interface (e.g. http://192.168.1.1).
  2. Navigate to Network → Interfaces → WAN and click Edit.
  3. Under Advanced Settings, uncheck "Use DNS servers advertised by peer".
  4. Enter {{.Host}} in the Custom DNS servers input and click Save & Apply.
  5. Or via SSH: uci set network.wan.peerdns=0 && uci add_list network.wan.dns='{{.Host}}' && uci commit network && /etc/init.d/network restart
{{end}} {{if not .IsPrivate}}

Desktop Setup (macOS & Windows)

macOS 14 (Sonoma) and later

1. Click the Download Config Profile button above.
2. Open System Settings → Privacy & Security → Profiles.
3. Double-click the downloaded ShieldDNS profile and click Install.
{{if not .SignEnabled}}Note: The "Not Signed" warning is normal for auto-generated profiles.{{end}}

Windows 11 (Native DoH)

1. Go to Settings → Network & internet → Wi-Fi (or Ethernet) → Hardware properties.
2. Next to "DNS server assignment", click Edit and change to Manual.
3. Enable IPv4. Set "Preferred DNS" to the IP address of this server.
4. Set "DNS over HTTPS" to On (manual template).
5. Under DoH template, enter:

https://{{.Host}}/dns-query

6. Click Save.
